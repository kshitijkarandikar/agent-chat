Tools are the agent's hands. Each tool is a file in the tools folder. The agent reads each tool's name and description, and decides by itself when to use it. Switch a tool off to see what the agent does without it.

Skills are know-how for your agent: instructions in plain words, like a short manual. Each skill is a folder with a SKILL.md file in the skills folder. The agent always sees each skill's name and description, and reads the full instructions only when a task needs them.
Add a skill
Public skills are shared as folders with a SKILL.md file, for example on github.com/anthropics/skills. Upload the SKILL.md here, or copy the whole folder into the skills folder.
